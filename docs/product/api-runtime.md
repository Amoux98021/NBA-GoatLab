# Probabilistic ranking API runtime

The FastAPI application is `goatlab.product.api:app`. It serves only frozen release data through
`RankingServingRepository`; route functions contain no ranking or score calculation. Set
`GOATLAB_BACKEND_MODE=artifact` for offline inspection or `postgres` for database reads.

| Variable | Default | Meaning |
|---|---|---|
| `GOATLAB_ENVIRONMENT` | `local` | `local`, `test`, or `production`. |
| `GOATLAB_BACKEND_MODE` | `artifact` | `artifact` or `postgres`. |
| `DATABASE_URL` | unset | Required for Postgres mode; keep secret. |
| `GOATLAB_PRODUCT_ARTIFACT_ROOT` | `data/product` | Parent directory of immutable release artifacts. |
| `GOATLAB_RELEASE_ID` | frozen STEP-0016 ID | No silent release fallback. |
| `GOATLAB_RELEASE_FINGERPRINT` | frozen STEP-0016 SHA-256 | Checked against DB and draws at startup. |
| `GOATLAB_ALLOWED_CORS_ORIGINS` | `http://localhost:3000` | Comma-separated explicit origins; wildcard forbidden in production. |
| `GOATLAB_DRAW_CACHE_ENABLED` | `true` | Process-local bounded repeated-pair cache; draws load once regardless. |

Routes under `/api/v1`:

| Route | Response |
|---|---|
| `GET /health` | `OK`/`DEGRADED`, configured release, DB connectivity, verified/lazy-loaded draw state, rights gate; degraded returns 503. |
| `GET /releases` and `GET /releases/{id}` | Fingerprinted release metadata; unknown ID 404. |
| `GET /leaderboard` | Stable `display_position` ordering with `limit`, `offset`, normalized partial `search`, `active`, `status`, and optional exact `release`; returns total plus typed entries. |
| `GET /top100` | Exact 100 frozen product payloads in frozen order. |
| `GET /players/{id}` | Complete typed profile, including unavailable players; unknown ID 404. |
| `GET /compare/{a}/{b}` | Aligned-draw probability, complement, tie probability, frozen ordering label, intervals and dimension evidence; same ID 400, unknown 404, known unavailable 422. |
| `GET /methodology` | Public versions, cutoff, disclosure text, and rights gate; no forensic payload dump. |

`/openapi.json` is generated by FastAPI from Pydantic domain and envelope models. The API has no
write routes and no authentication requirement for public reads, but deployment must use a
read-only database role. CORS accepts only configured origins. The leaderboard display position
is navigational, not an exact scientific order; wider uncertainty is not lower quality. The
publication-rights gate remains `PUBLICATION_RIGHTS_REVIEW_REQUIRED`.

The paired NPZ is hash-verified at repository startup, decompressed into memory on first
comparison, and reused. A 4,096-entry process-local cache optionally avoids repeat arithmetic;
it never changes the frozen probability. The store fails startup if the file is absent or its
fingerprint disagrees. DB mode fails startup if the configured release is absent or has a
different fingerprint. Later DB connection loss is shown as degraded health; no fallback to
another release occurs.
