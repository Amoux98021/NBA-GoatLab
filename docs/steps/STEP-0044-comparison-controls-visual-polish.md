# STEP-0044 — Comparison controls and visual polish

The head-to-head controls now edit seven integer percentages over a fixed 100% budget.
Hold the edited category at the chosen value; allocate the remaining budget in the
other categories' existing proportions with largest-remainder rounding (ties use
the original category order). Consecutive edits to one slider use a stable basis
so the result does not depend on drag speed. If a shared single-category or zero
state has no other positive weight, use the GOAT Lab default ratios for the others.

The experimental score contract, official defaults, frozen inputs and endpoint arithmetic
are unchanged. Existing v1 URLs retain their exact
units and score, while the slider shows rounded percentages (with a disclosure)
until the first edit. Previously shared all-zero vectors remain disabled, but
an edit from one re-enters the fixed 100% budget. Share, swap and reset retain
their semantics. No additional requests are generated by moving sliders.

Comparison results now attach to the search input, wrap long labels, keep their
desktop and mobile scroll bounds, and expose keyboard focus. Info notes use an
anchored, viewport-clamped disclosure, above or below as room allows. The JS note
escapes clipped parent containers; native details still works without JavaScript.
This is a frontend-only change, not a model, data, rank, calibration, or deployment change.

Release branch is based directly on the published `1943d1f` frontend. It also
takes the package manifest and exact lockfile from STEP-0035 (`cfdbc54`),
replacing the affected Next.js 16.3.5 graph before deploying. React pins,
runtime configuration and all back-end code and data are unchanged.
The current release pins Next.js and the matching ESLint config to 16.4.6
instead of restoring STEP-0035's 16.4.3, which predates later advisories.
The production dependency audit reports zero findings. A separate full audit
still reports one moderate development-only lint advisory chain (seven related
development package entries); no runtime packages are affected in the audit.

This exact dependency graph passed lint, typecheck, a production webpack build,
and all 28 frontend tests against the local frozen artifact API, with no skips.
Chrome acceptance passed at 375, 768, 1024 and 1440 CSS pixels, with zero browser
exceptions or external requests. Checked keyboard adjustments, recovery from
100%, exact share and swap/reload, reset, legacy links, keyboard dismissal,
dropdown alignment, three anchored notes per width and no horizontal overflow.
The local production response kept `noindex, nofollow, noarchive`.
